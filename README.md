## Cuentos

### 👑 La princesa Lila comparte
Cuento para niños de ~2 años. Enseñanza: **compartir**.

- **Archivo:** [`cuento-princesa-lila.html`](cuento-princesa-lila.html)
- **Páginas:** 4
- **Ilustraciones:** dibujos SVG hechos por código (self-contained, no necesita archivos externos)

Para leerlo, descarga el archivo y ábrelo en cualquier navegador.

#### Historia
1. Esta es la princesa Lila. Vive en un castillo rosa.
2. Lila tiene muchos juguetes. ¡Pero juega sola!
3. Llega su amiga Rosa. Rosa no tiene juguetes.
4. Lila dice: ¡Toma! Juntas juegan felices. 💕

#### Usar imágenes generadas con IA (opcional)
El cuento ya incluye ilustraciones SVG. Si prefieres usar imágenes generadas con IA
(DALL·E, Midjourney, Bing Image Creator, etc.), guarda 4 imágenes como
`pagina1.png` … `pagina4.png` junto al HTML y sustituye cada bloque `<svg>...</svg>`
por `<img src="pagina1.png" alt="...">`.
