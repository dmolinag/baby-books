## Cuentos

### 👑 La princesa Lila y el jardín mágico 🌸
Cuento para niños de ~2 años. Enseñanza: **compartir**.

- **Archivo:** [`cuento-princesa-lila.html`](cuento-princesa-lila.html)
- **Páginas:** 8 + moraleja
- **Ilustraciones:** dibujos SVG hechos por código (self-contained, no necesita archivos externos)

Para leerlo, descarga el archivo y ábrelo en cualquier navegador.

#### Historia
1. Había una vez una princesa llamada Lila, que vivía en un castillo rosa.
2. Detrás del castillo había un jardín mágico con flores que brillaban como estrellas.
3. En el jardín crecía un árbol encantado con frutas de colores que sabían a caramelo.
4. Un día llegó un hada pequeñita llamada Rosa, que venía de lejos con mucha hambre.
5. Pero solo quedaba una fruta en el árbol. Lila dudó: «¿Qué hago?».
6. Lila sonrió: «¡Toma, Rosa! Es para ti», y le dio su última fruta.
7. El árbol brilló con luz mágica y, por compartir, se llenó otra vez de frutas.
8. Desde ese día Lila y Rosa fueron mejores amigas, felices y juntas.

> 💛 Moraleja: cuando compartimos, la alegría se hace más grande.

#### Usar imágenes generadas con IA (opcional)
El cuento ya incluye ilustraciones SVG. Si prefieres usar imágenes generadas con IA
(DALL·E, Midjourney, Bing Image Creator, etc.), guarda las imágenes como
`portada.png`, `pagina1.png` … `pagina8.png`, `fin.png` junto al HTML y sustituye
cada bloque `<svg>...</svg>` por `<img src="pagina1.png" alt="...">`.
